# クレーンパラダイス (WebGL クレーンゲーム)

`index.html` 1ファイルで動く、物理演算つきの2ボタン式クレーンゲームです。
Gatsby の `static/` に置いてあるので、ビルド後は `/crane-game/` で遊べます。

- 描画: [three.js](https://threejs.org/) r169（PBR マテリアル、ぬいぐるみの起毛表現に sheen、透過ガラス、ソフトシャドウ、ブルーム、ビネット）
- 物理: [cannon-es](https://github.com/pmndrs/cannon-es) 0.20（240Hz 固定ステップ）
- 音: WebAudio で効果音・BGM・モーター音をその場で合成（音声ファイルなし）
- ライブラリは jsDelivr CDN から import map で読み込みます

## 操作

| 入力 | 動作 |
| --- | --- |
| `C` / 100円ボタン | コイン投入 |
| `→` / ①ボタン | 押している間だけ右へ（1プレイ1回） |
| `↑` / ②ボタン | 押している間だけ奥へ。離すとアームが下りる |
| `V` | 視点切替（正面 / 横からのぞく / 上） |
| `M` | ミュート |
| ドラッグ・ホイール | カメラ操作 |

## アームの仕組み

- 3本の爪はそれぞれ「トルク制限モーター」として動きます。接触力が `GRIP_FORCE` 未満なら閉じ、上限で止まり、押し負けると開きます。
- 爪の先が景品に乗り、反力がアームの自重 (`CLAW_WEIGHT`) を超えるとケーブルがたるんだとみなして降下を止めます。
- 2本以上の爪が触れている景品は、力の上限つきの保持ジョイントで爪につながります。中心からずれたつかみ方や2本だけのつかみ方は保持力が弱くなります。
- 上まで上がると保持力が毎回ランダムに弱まります（たまに強い回もあります）。景品の重さや揺れに負けると、爪の間からすべり落ちます。

難易度は `index.html` 冒頭の `GRIP_FORCE` / `HOLD_FORCE` と、`beginPlay()` の `claw.weak` で調整できます。
