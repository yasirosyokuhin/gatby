# クレーンパラダイス (WebGL ゲームセンター)

`index.html` 1ファイルで動く、物理演算つきのゲームセンターです。店内を一人称で歩き、台の前に立って遊びます。
Gatsby の `static/` に置いてあるので、ビルド後は `/crane-game/` で遊べます（Netlify は `public/` をそのまま公開するため `public/crane-game/` にも同じファイルを置いています）。

- 描画: [three.js](https://threejs.org/) r169（PBR、ぬいぐるみの起毛表現に sheen、透過ガラス、ソフトシャドウ、ブルーム）
- 物理: [cannon-es](https://github.com/pmndrs/cannon-es) 0.20（240Hz 固定ステップ、台ごとに独立したワールド）
- 音: WebAudio で効果音・BGM・モーター音を合成（音声ファイルなし）

## 操作

| 場面 | 入力 | 動作 |
| --- | --- | --- |
| 店内 | `W A S D` / 矢印 | 移動（`←` `→` で向きを変える、Shift で早歩き） |
| 店内 | ドラッグ | 見回す（スマホは左下のスティックで移動） |
| 店内 | `E` / 台をクリック | 目の前の台で遊ぶ |
| 台 | `C` / 100円ボタン | コイン投入 |
| 台 | `→` / ① | 押している間だけ右へ（1プレイ1回） |
| 台 | `↑` / ② | 押している間だけ奥へ。離すと降下 |
| 台 | `V` / `Esc` | 視点切替 / 台をはなれる |

- 右上のアイコン: 台をはなれる / 視点切替 / 横カメラON・OFF（ONのとき水色）/ 音のON・OFF。
- 横カメラ: ②を押すと真横から見て奥行きを合わせられます。クレーン台はアームが下りてつかみ、少し上がるまで横のまま、その後は正面に戻って見届けます。リングフック台は、②を離してリングが下り始めると、フックとリングに寄った斜め上からの視点になり、掛かったかどうかがよく見えます。1プレイが終わると正面に戻ります。
- 台の前で遊んでいないときは、左右スワイプ（または画面端の ‹ › / `[` `]` キー）で画面の左右どおり隣の台に切り替えられます。列の端から反対の列へ移るときは、カメラを回さずに一瞬暗転して切り替えます。コインを入れてからプレイが終わるまでは切り替えられません。クレジットが残っていても次のプレイは自動では始まらず（① を押すと始まる）、その間は台を移動できます（クレジットはその台に残る）。歩いて移動することもできます。
- 縦長の画面では、カメラを引かずに画角を広げて台が収まるようにしています。
- アームの真下に赤いLEDの照準が表示されます（手前の景品に隠れているときはうすく透けて見えます）。
- プレイ中のカメラは、正面から左右50°・ズームは台が見える範囲に制限しています。

## 台

照明は台の天井のすぐ下にあるので、高い位置にあるアームやガントリーの影は床に大きく引き伸ばされてしまう。ガントリーは影を落とさず、アームやリングは床・景品の近くに来たときだけ影を落とす（そのときの影はほぼ実寸）。

店内は2列で、手前の列に「缶バッジリング・ペラ輪キャッチ・マスコットいっぱい・ツインアームUFO・クレーンパラダイス・日用品リングフック・野菜リングフック・お菓子リングフック・くるくるテーブル・末広がり橋渡し・スウィートランド」、
奥の列（反対向き）に「釣り下げマスコット・段差おかし落とし・ドリンクリングフック・Dリングキャッチ・たこ焼きボール・橋渡しフィギュア・台湾キャッチャー・でっかいぬいぐるみ・ちゃぶ台ぬいぐるみ・おもりカプセル」の全21台が並んでいます。
クレーン台はすべて `ClawMachine` の preset（`CLAW_PRESETS`）で作り分けています。

### クレーンパラダイス（3本爪）
- 爪はそれぞれ「トルク制限モーター」。接触力が `GRIP` 未満なら閉じ、上限で止まり、押し負けると開く。
- 爪先が景品に乗って反力がアーム自重 (`WEIGHT`) を超えるとケーブルがたるんだとみなして降下を止める。
- 2本以上の爪が触れている景品は、力の上限つき保持ジョイントで爪につながる。上昇後は保持力が毎回ランダムに弱まり、重さや揺れに負けるとすべり落ちる。

### 日用品リングフック
ゲームセンターで流行している「フック設定」の台を再現しています。景品は1つです。
- クレーンの先には爪がなく、ボールチェーン（質点を距離拘束でつないだもの）の先に金属リングが下がっている。移動するとリングが振り子のように揺れる。
- 2本の横棒の上に板が載っていて、板の中央に金具の「?」形フックが立っている。板の手前からチェーンが下の金網トレーにつながっている。
- クレーンは決まった量だけ下がり（下降量）、リングは板の上に立つ。巻き上げで手前からフックの下へ滑り込むと、フックの巻きの内側に掛かる（「手前から滑り込み」）。
- 掛かったまま上がると板が持ち上がり、チェーンが金網トレーの手前を引き上げてトレーが傾き、景品が落ちて GET。掛かっていなければ板は動かない。
- 板は横棒・ストッパー・ガイドピンで支えられ、水平のまま上下にだけ動く。上で板を吊ったままのときは一度下ろしてからリングを外す。
- リングがフックに掛かって板が持ち上がり始めたら、リングと板をつないで上まで必ず持ち上げる（途中で外れて「掛かったのに取れない」ことがない）。金網トレーは手前の辺が蝶番で、奥が引き上げられると景品は手前へすべり落ちる。上で残っていたら軽く押して落とす。
- 重すぎると巻き上げモーターが止まる (`LIFT_MAX`)。景品が取られると、トレーが戻ってから次の景品が置かれる。

### リングフック台のバリエーション（景品はジャンル別）
仕組みは日用品リングフックと同じで、台ごとにフックやリングの向き・大きさと、景品のジャンルが違います。景品の絵柄はすべてオリジナルです。

| 台 | 特徴 | 景品 |
| --- | --- | --- |
| 日用品リングフック | 正面向きのフック | ティッシュ、トイレットペーパー、キッチンペーパー、洗剤、食器用洗剤、歯みがき粉、シャンプー、ハンドソープ、スポンジ、ウェットティッシュ、ゴミ袋 |
| 野菜リングフック | フックの腕が左向き。左右の揺れでかける | メロン、キャベツ、玉ねぎ、にんじん、じゃがいも、トマト、とうもろこし、なす、ブロッコリー、かぼちゃ |
| お菓子リングフック | リングが小さい（半径3.6cm、ふつうは5cm）。フックの先を正確に狙う上級台 | ポテトチップスBIG、チョコ、クッキー缶、グミ、せんべい、チョコスティック |
| ドリンクリングフック | リングが斜め前（45°）を向いて吊られている。向きを読んでかける | 2Lペットボトル、缶6本パック、紙パックジュース、お茶2本 |

- リングはチェーンの弱いねじれで、吊られた向き（正面、または斜め前）に戻ろうとする。揺れはガントリーの加減速・チェーン・接触から自然に生まれる。
- ②を押している間は右からの真横カメラ。離してリングが下り始めると、フックとリングに寄った斜め上からの視点になり、掛かったかどうかがよく見える。

### マスコットいっぱい（小さい3本爪）
小さなマスコット（ぬいぐるみを 0.55 倍に縮めたもの）が山盛りの台。爪とハブも小さく、保持力も弱め。

### ツインアームUFO（2本爪）
左右2本の爪で挟む UFO キャッチャー型。3本爪より支えが少ないので、重心の真上をつかまないとすべり落ちやすい。

### でっかいぬいぐるみ（確率機）
大きなシマエナガ、またはオリジナルのパステルうさぎが1つだけ入った台。爪は大きいが、ふだんは持ち上げた直後に保持力がほぼ抜ける（`weak = 0.1`）。
プレイ回数が「天井」（8〜15回のランダム）に達した回だけアームが強くなる、いわゆる確率機です。

### 台湾キャッチャー（バンバンキャッチャー）
お店の台のように、景品をガラスいっぱいに山積みにした台です。
- 奥はひな壇で、大盛りカップやきそば（オリジナルの絵柄）をふたを手前に向けて天井近くまで積み上げている。手前の台にはポテトチップスの袋とカップめんが山盛り。
- いちばん手前に透明の低いシールドがあり、その向こうが取り出し口。シールドを越えて落ちれば GET。
- アームは先端がゴム爪の3本爪。根元の特殊な金具で、ふだんは「斜め奥」を向いている。下りるときはまっすぐになり、上まで上がると力が抜けて、ばねで斜め奥の基本姿勢へ一気に戻る。その勢いで景品は後ろ（奥）へ放り投げられる。
- 取り方は「押して崩す」「投げて別の景品にぶつける」「転がして寄せる」。奥へ投げた景品や爪が山を崩し、手前の袋がシールドを越えて雪崩のように落ちる。
- 保夾（ほきょう・保証取物）: 規定回数（6〜11回のランダム）に達すると「保夾モード」になり、景品が取れるまで毎回アームが強くなる（爪1本でも確実につかみ、力が抜けずに取り出し口まで運ぶ）。
- 景品が多いので、止まった景品は物理計算を眠らせ、アームや落ちてきた景品が触れたときだけ起こす。

参考: [掴んで投げる！台湾UFOキャッチャー攻略（クレーンゲームパーティー）](https://crane-game-party.cgp-corp.co.jp/taiwan/)、[台湾キャッチャーの取り方（GRAB IT）](https://grabbit.co.jp/onkure/taiwancatcher/)、[台湾クレーンゲームの本質は「自販機」？（note）](https://note.com/yachia/n/n5a9c1f719ed6)、[台湾のクレーンゲーム実態調査](https://ameblo.jp/teritamablog/entry-12916569757.html)、[バンバンキャッチャー命名（日本クレーンゲーム協会）](https://www.dreamnews.jp/press/0000354169)

### 橋渡しフィギュア
2本の平行なバー（橋）の上に箱入りフィギュアを載せ、箱を少しずつずらしてバーのすき間に落とす台です（[橋渡しの基本と取り方](https://grabbit.co.jp/onkure/bridging/)、[セガプラザ 橋渡し①](https://segaplaza.jp/special/ufo/tips-of-getting-prize-figure/)・[②](https://segaplaza.jp/special/ufo/tips-of-getting-prize-figure-2/)、[縦ハメと横ハメ](https://detail.chiebukuro.yahoo.co.jp/qa/question_detail/q10259621025)を参考）。
- バーは台の幅いっぱいの金属棒で、左右の壁に金具で固定。滑り止めのピンクのゴムチューブを巻いてある（滑り止めがあると箱が動きにくい）。
- 箱（18×12×28cm、オリジナルのキャラクター）はバーに対して縦向き（奥行き方向）に渡してある。上面に透明の窓があり、中のフィギュアが見える。
- バーのすき間（12.8cm）は箱の厚み（12cm）よりわずかに広く、箱の長さより狭い。箱が縦にならないと落ちない（縦ハメ）。床全体が取り出し口。
- アームは左右に開く2本爪。爪はバーを通り抜けられず、下りるとバーに乗って止まる。すき間の真上なら爪がバーの間に入り込む。景品をつかんで保持する力はなく、爪先で押す・端を持ち上げるだけ。
- 箱の端をまたぐように下ろすと、閉じた爪先が端の下に入って持ち上げ、箱は反対側のバーの上をすべって少しずつずれていく。端がバーから外れると、すき間にはまって（ハマり）縦になって落ちる。

### たこ焼きボール
クレーンでピンポン球を拾い、たこ焼き器のような鉄板の上に落とす台です。
- 奥はピンポン球のプール、手前のまん中に丸いくぼみ（18個）の並んだ鉄板。鉄板の左右は鉄板へ下る坂で、外へはねた球も鉄板へ戻る。アームは拾った球を鉄板のまん中（ふりわけドームの真上）まで運んで離し、球ははずんで転がり、どこかの穴に収まる。
- 赤く光る「あたり」の穴（毎ラウンド1つ）に球が入れば GET。奥の見本棚に景品（ちびくま・もちもち・お菓子BOX）が並び、「今回はコレ！」の付いた景品が手前の取り出し口に出てくる。
- はずれの穴に入った球はそのまま残るので、穴が埋まるほど当たりやすくなる。当たりが出るか、プールの球が少なくなると、球はプールに戻って次のラウンドになる。
- 当たり判定は四角い開口の格子で、球は穴のふちに乗って半分沈む（たこ焼き器のくぼみ）。

### Dリングキャッチ
箱の上に樹脂のD形リングが付いた景品を、アームの爪をリングに通して持ち上げる台です。
- アームは細い爪の2本爪。リングの輪は左右を向いているので、②を押したときの横カメラで輪の位置を合わせる。
- 爪がリングの向こう側の箱の上に下りるように狙うと、閉じる爪がリングをくぐり、上がるときにリングの上の棒が爪先に掛かって箱が持ち上がる。
- 景品をつかんで保持する力はない（リングに掛かっているだけ）。上でアームの力が抜けると爪が少し開き、弱い回はリングが爪先からすべって落ちる。
- 倒れてリングが上を向いていない箱は、店員さんが起こす。

### ちゃぶ台ぬいぐるみ
支柱の上の小さな丸い木のテーブル（ちゃぶ台）に、大きなぬいぐるみが1つ載っている台です。テーブルから落ちれば、どこに落ちても GET（床全体が取り出し口）。
- アームで押す・引っぱる・転がす。テーブルのふちに寄せていき、最後にはみ出したところで落とす。
- 実機の攻略でいう「ちゃぶ台返し」: ぬいぐるみの片側に爪を差し込んですくい上げ、ひっくり返すように転がして落とす。
- アームの爪は、テーブルの上ではテーブルに、外では床に当たって止まる。

### くるくるテーブル（回転テーブル）
ゆっくり回る円盤の上に小さなぬいぐるみが並んでいる台です。景品は円盤と一緒に回るので、アームが下りるまでの時間を見越して、狙った景品が来る位置に合わせる。
- 円盤は運動学的に回転し（毎秒約0.55rad）、景品は摩擦で一緒に回る。取り出し口は円盤の外の手前左。

### 段差おかし落とし（前落とし）
奥ほど高い3段の台に、お菓子の箱が並んでいる台です。手前の段の先が取り出し口で、箱を押し出して落とせば GET。
- 2本爪のアームで箱を手前へ押す・引っかける。奥の段から押し出した箱が、手前の段の箱を押し出すこともある。

### ペラ輪キャッチ
マスコットの入った箱の上に、薄くてやわらかいプラスチックの輪（ペラ輪）が立っている台です。輪の面は左右を向いている。
- 細い爪を輪の横の箱の上に下ろし、閉じる動きで爪を輪に押し当てる。輪はやわらかいので、押し当たった爪先に輪が掛かり、そのまま持ち上がる。
- 輪に掛かっているだけなので、上でアームの力が抜けると弱い回は輪が外れて落ちる。左右交互に掛けて、箱を取り出し口へずらしていく。
- 倒れて輪が上を向いていない箱は、店員さんが起こす。

### 缶バッジリング
手前ほど低い坂の棚に、Oリング付きの缶バッジが寝かせて並んでいる台です。棚の手前のふちから落ちれば GET。
- 細い2本爪の爪先をリングの穴に入れると、リングが爪先に掛かって持ち上がる（バッジがぶら下がる）。リングの端を狙う。
- 掛かったまま取り出し口まで運べれば GET。弱い回は上でリングが外れ、坂を少しすべる。

### 末広がり橋渡し
2本のバーの間隔が、左は狭く右へ行くほど広がっている橋渡しです。小さめのフィギュア箱が狭い側に載っている。
- 爪は箱を持ち上げられず、押す・回すだけ。箱を広い側（右）へ寄せる、または回して斜めにすると、間から落ちる。
- 爪はバーに当たると止まる（通常の橋渡しと同じ）。

### スウィートランド
回転テーブルのお菓子をショベルですくい、動くプッシャーテーブルに落とす台です（クレーンではない）。
- ① で、回転テーブルの手前を往復するショベルを下ろす。ショベルの口は回ってくるお菓子の方を向いていて、テーブルの回転でお菓子が入ってくる。
- すくったあとショベルは手前を向き、上段テーブルの上を左右に往復する。② で傾けてお菓子を落とす（8秒で自動）。
- 上段と下段のテーブルは前後に交互に動き、奥の壁に押されたお菓子が段から押し出される。下段の手前から落ちたお菓子が GET。
- 回転テーブルのお菓子が少なくなると、店員さんが補充する。

### 釣り下げマスコット
右の壁から取り出し口の上へ向かって下がっている2本の棒に、輪の付いたマスコットが掛かっている台です。棒の先から外れて落ちれば GET。
- 2本爪のアームで、マスコットの奥側（棒の根元側）を押して、棒の先へ少しずつ送る。輪は棒を通り抜けず、棒に沿ってすべる。
- 1回で落とすのは難しく、何回か押して先まで送る。

### おもりカプセル（バンビーノ型の確率機）
鍵の入った重いカプセルを落とすと、奥の棚に並んだ高額景品（ゲーム機・ヘッドホン・スマート時計）のどれかと交換できる台です。
- つかんで持ち上げることはできるが、設定額に届くまでは上がりきったところで必ずアームが開いて落とす。
- 設定額（何回か遊んだあと）に届いた回だけ、取り出し口まで運ぶ。カプセルを押して取り出し口に落とすこともできる。

### ぬいぐるみの質感
- 顔や体の細部: つやのある目（白い光つき）、内耳の明るい布、刺しゅうの鼻と口、肉球、ねこのひげ、縫い付けタグ。大きな部品はなめらかな球で作る。
- 毛並みはシェル法: 各パーツの外側に薄い殻を3枚重ね、毛の1本1本に当たる点だけを描く。輪郭がふわっとほつれ、根元ほど暗く、毛ごとに少し色が違う。目・鼻・肉球は毛の上に付く。毛は近くの台だけ描く。
- 布は光沢がなく、ふちが白っぽく光る（広い sheen）。
- ぬいぐるみどうし・床との接触はやわらかく（少し沈み込み、はずまない）、何かに触れているぬいぐるみには転がり抵抗がかかるので、床の上を転がり続けない。おもちは平たい形の当たり判定。

難易度は各クラスの `K`（定数）と `onBegin()` で調整できます。
