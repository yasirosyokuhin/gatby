# クレーンパラダイス (WebGL ゲームセンター)

`index.html` 1ファイルで動く、物理演算つきのゲームセンターです。店内を一人称で歩き、台の前に立って遊びます。
Gatsby の `static/` に置いてあるので、ビルド後は `/crane-game/` で遊べます（Netlify は `public/` をそのまま公開するため `public/crane-game/` にも同じファイルを置いています）。

- 描画: [three.js](https://threejs.org/) r169（PBR、ぬいぐるみの起毛表現に sheen、透過ガラス、ソフトシャドウ、ブルーム）
- 物理: [cannon-es](https://github.com/pmndrs/cannon-es) 0.20（240Hz 固定ステップ、台ごとに独立したワールド）
- 音: WebAudio で効果音・BGM・モーター音を合成（音声ファイルなし）

## 操作

| 場面 | 入力 | 動作 |
| --- | --- | --- |
| 店内 | `W A S D` / 矢印 | 移動（`←` `→` で向きを変える、Shift で早歩き） |
| 店内 | ドラッグ | 見回す（スマホは左下のスティックで移動） |
| 店内 | `E` / 台をクリック | 目の前の台で遊ぶ |
| 台 | `C` / 100円ボタン | コイン投入 |
| 台 | `→` / ① | 押している間だけ右へ（1プレイ1回） |
| 台 | `↑` / ② | 押している間だけ奥へ。離すと降下 |
| 台 | `V` / `Esc` | 視点切替 / 台をはなれる |

- 右上のアイコン: 台をはなれる / 視点切替 / 横カメラON・OFF（ONのとき水色）/ 音のON・OFF。
- 横カメラ: ②を押すと真横から見て奥行きを合わせられます。アームが下りてつかみ、少し上がるまで横のまま、その後は正面に戻って見届けます。1プレイが終わると正面に戻ります。
- プレイ中は左右スワイプ（または画面端の ‹ › / `[` `]` キー）で隣の台に切り替えられます。歩いて移動することもできます。
- 縦長の画面では、カメラを引かずに画角を広げて台が収まるようにしています。
- アームの真下に赤いLEDの照準が表示されます（手前の景品に隠れているときはうすく透けて見えます）。
- プレイ中のカメラは、正面から左右50°・ズームは台が見える範囲に制限しています。

## 台

店内は2列で、手前の列に「マスコットいっぱい・ツインアームUFO・クレーンパラダイス・日用品リングフック・野菜リングフック」、
奥の列（反対向き）に「Dリングキャッチ・たこ焼きボール・橋渡しフィギュア・台湾キャッチャー・でっかいぬいぐるみ」の全10台が並んでいます。
クレーン台はすべて `ClawMachine` の preset（`CLAW_PRESETS`）で作り分けています。

### クレーンパラダイス（3本爪）
- 爪はそれぞれ「トルク制限モーター」。接触力が `GRIP` 未満なら閉じ、上限で止まり、押し負けると開く。
- 爪先が景品に乗って反力がアーム自重 (`WEIGHT`) を超えるとケーブルがたるんだとみなして降下を止める。
- 2本以上の爪が触れている景品は、力の上限つき保持ジョイントで爪につながる。上昇後は保持力が毎回ランダムに弱まり、重さや揺れに負けるとすべり落ちる。

### 日用品リングフック
ゲームセンターで流行している「フック設定」の台を再現しています。景品は1つです。
- クレーンの先には爪がなく、ボールチェーン（質点を距離拘束でつないだもの）の先に金属リングが下がっている。移動するとリングが振り子のように揺れる。
- 2本の横棒の上に板が載っていて、板の中央に金具の「?」形フックが立っている。板の手前からチェーンが下の金網トレーにつながっている。
- クレーンは決まった量だけ下がり（下降量）、リングは板の上に立つ。巻き上げで手前からフックの下へ滑り込むと、フックの巻きの内側に掛かる（「手前から滑り込み」）。
- 掛かったまま上がると板が持ち上がり、チェーンが金網トレーの手前を引き上げてトレーが傾き、景品が落ちて GET。掛かっていなければ板は動かない。
- 板は横棒・ストッパー・ガイドピンで支えられ、水平のまま上下にだけ動く。上で板を吊ったままのときは一度下ろしてからリングを外す。
- リングがフックに掛かって板が持ち上がり始めたら、リングと板をつないで上まで必ず持ち上げる（途中で外れて「掛かったのに取れない」ことがない）。金網トレーは手前の辺が蝶番で、奥が引き上げられると景品は手前へすべり落ちる。上で残っていたら軽く押して落とす。
- 重すぎると巻き上げモーターが止まる (`LIFT_MAX`)。景品が取られると、トレーが戻ってから次の景品が置かれる。

### 野菜リングフック
日用品リングフックと同じ仕組みで、フックの腕が左を向いている台です。リングはどの台でも正面向きに吊られています（チェーンの弱いねじれだけで、向きをそろえる力はかけていない）。揺れはガントリーの加減速・チェーン・接触から自然に生まれ、左右にも前後にも揺れるので、揺れとねじれのタイミングでフックに通します。
景品はメロン（緩衝材つき）・キャベツ・玉ねぎ（ネット入り）・にんじん・じゃがいも（袋入り）。丸いメロンやキャベツは少し傾いただけで転がり落ちます。

### マスコットいっぱい（小さい3本爪）
小さなマスコット（ぬいぐるみを 0.55 倍に縮めたもの）が山盛りの台。爪とハブも小さく、保持力も弱め。

### ツインアームUFO（2本爪）
左右2本の爪で挟む UFO キャッチャー型。3本爪より支えが少ないので、重心の真上をつかまないとすべり落ちやすい。

### でっかいぬいぐるみ（確率機）
大きなシマエナガ、またはオリジナルのパステルうさぎが1つだけ入った台。爪は大きいが、ふだんは持ち上げた直後に保持力がほぼ抜ける（`weak = 0.1`）。
プレイ回数が「天井」（8〜15回のランダム）に達した回だけアームが強くなる、いわゆる確率機です。

### 台湾キャッチャー（バンバンキャッチャー）
お店の台のように、景品をガラスいっぱいに山積みにした台です。
- 奥はひな壇で、大盛りカップやきそば（オリジナルの絵柄）をふたを手前に向けて天井近くまで積み上げている。手前の台にはポテトチップスの袋とカップめんが山盛り。
- いちばん手前に透明の低いシールドがあり、その向こうが取り出し口。シールドを越えて落ちれば GET。
- アームは後ろに傾いた3本爪。下りるときはまっすぐになり、上まで上がると力が抜けて傾いた基本姿勢へ一気に戻る。その勢いで景品が手前へ放り出される（つかんだ位置しだいで取り出し口に届くか、山に当たるか）。
- 天井（6〜11回のランダム）に達した回だけ、力が抜けずに取り出し口まで運ぶ。
- 山に爪が刺さったり投げた景品が当たったりすると、手前の袋が押し出されて雪崩のように落ちることがある。
- 景品が多いので、止まった景品は物理計算を眠らせ、アームや落ちてきた景品が触れたときだけ起こす。

参考: [掴んで投げる！台湾UFOキャッチャー攻略（クレーンゲームパーティー）](https://crane-game-party.cgp-corp.co.jp/taiwan/)、[台湾キャッチャーの取り方（GRAB IT）](https://grabbit.co.jp/onkure/taiwancatcher/)、[バンバンキャッチャー命名（日本クレーンゲーム協会）](https://www.dreamnews.jp/press/0000354169)

### 橋渡しフィギュア
手前と奥の2本のゴム巻きバーの上に、箱入りフィギュア（オリジナルの絵柄）が縦長にまたがって置いてある台です。すき間は箱の厚みよりわずかに広く、箱の長さより狭いので、箱が縦にならないと落ちません。
- アームは左右に開く2本爪。爪はバーを通り抜けられず、下りるときはバーに乗って止まり、閉じるときや上がるときはバーに押されて開く。すき間の真上なら爪がバーの間に入り込む。
- アームは景品を「つかんで保持」しない。爪先で箱を押す・箱の端の下に入れて持ち上げるだけで、重さに負けると爪が開いてすべる。
- 箱の端をまたぐように下ろすと、爪がバーに乗り、閉じた爪先が箱の下に入って端を持ち上げる。箱は少しずつずれていき、端がバーから外れると落ちる（ずらし・縦ハメ）。
- 参考: [橋渡しの取り方（セガプラザ）](https://segaplaza.jp/special/ufo/tips-of-getting-prize-figure/)、[縦ハメの取り方](https://curiousvv.jp/cranegame-hashiwatashi-tate/)

### たこ焼きボール
クレーンでピンポン球を拾い、たこ焼き器のような鉄板の上に落とす台です。
- 奥はピンポン球のプール、手前は丸いくぼみ（34個）の並んだ鉄板。アームは拾った球を鉄板のまん中（ふりわけドームの真上）まで運んで離し、球ははずんで転がり、どこかの穴に収まる。
- 赤く光る「あたり」の穴（毎ラウンド2つ）に球が入れば GET。手前の取り出し口にカプセル景品が出てくる。
- はずれの穴に入った球はそのまま残るので、穴が埋まるほど当たりやすくなる。当たりが出るか、プールの球が少なくなると、球はプールに戻って次のラウンドになる。
- 当たり判定は四角い開口の格子で、球は穴のふちに乗って半分沈む（たこ焼き器のくぼみ）。

### Dリングキャッチ
箱の上に樹脂のD形リングが付いた景品を、アームの爪をリングに通して持ち上げる台です。
- アームは細い爪の2本爪。リングの輪は左右を向いているので、②を押したときの横カメラで輪の位置を合わせる。
- 爪がリングの向こう側の箱の上に下りるように狙うと、閉じる爪がリングをくぐり、上がるときにリングの上の棒が爪先に掛かって箱が持ち上がる。
- 景品をつかんで保持する力はない（リングに掛かっているだけ）。上でアームの力が抜けると爪が少し開き、弱い回はリングが爪先からすべって落ちる。
- 倒れてリングが上を向いていない箱は、店員さんが起こす。

### ぬいぐるみの質感
- 毛並みはシェル法: 各パーツの外側に薄い殻を3枚重ね、毛の1本1本に当たる点だけを描く。輪郭がふわっとほつれ、根元ほど暗く、毛ごとに少し色が違う。目・鼻・肉球は毛の上に付く。毛は近くの台だけ描く。
- 布は光沢がなく、ふちが白っぽく光る（広い sheen）。
- ぬいぐるみどうし・床との接触はやわらかく（少し沈み込み、はずまない）、何かに触れているぬいぐるみには転がり抵抗がかかるので、床の上を転がり続けない。おもちは平たい形の当たり判定。

難易度は各クラスの `K`（定数）と `onBegin()` で調整できます。
